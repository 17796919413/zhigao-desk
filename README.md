# 知稿

品牌内容审稿工作台。网页内「连接与授权」提供手动设置；也可以让自己的本机 AI Agent 完成接入。

给 Agent 提供工作台地址并说「帮我接通知稿的 AI 审稿、飞书同步和本地归档」，由 Agent 读取 [接入说明](./AGENT_SETUP.md)，按 [机器可读清单](./setup-manifest.json) 检查、配置并验证。入口索引为 [llms.txt](./llms.txt)。

网页与 Agent 两种方式共用连接器、飞书登录和浏览器归档配置，无需重复设置。

连接与授权面板提供“检查更新”，无需先连接 AI；检测到新版后可直接更新连接器。首次安装 1.8.2 后，连接器启动时检查一次，运行期间每 6 小时检查，网络失败 15 分钟后重试，任务空闲时应用。Windows 支持从页面唤起已安装的连接器；旧版本首次迁移见接入说明。


当前发布版本为 **1.11.0**。

1.11.0 普通网址自动检测已运行的连接器，保留主动断开的选择；接入须以当前 Agent 实际调用工作台状态成功为准。品牌项目支持改名和删除，口径支持删除；删除会阻断旧审核上下文，品牌删除同时清理稿件、反馈、缓存及原件。每份稿件增加本轮专属反馈，支持文字、粘贴截图、Word、PPTX、PDF、TXT；附件文字与图片进入必读审核清单，不自动继承到新上传稿件。移除上传固定容量、字数和页数门槛，实际容量仍受设备资源限制。

反馈 PPTX 支持文字、备注和内嵌图片；图表、SmartArt、嵌入对象等不能完整读取时明确阻断完整审核，应提供 PDF。旧 .doc / .ppt 需另存为 .docx / .pptx / PDF。知稿能阻断过期依据和结果，不能擦除外部 AI 聊天历史。

本轮回归：`python -X utf8 tests/workbench_feedback_browser.py`。

1.10.0 将审稿资料改为完整分页读取，原文解析缓存按品牌和当前内容校验，分批核对支持保存及刷新恢复。资料变化会使旧凭据失效，返回更新目录供重新核对；旧检查仅供参考，不自动算已审。检查点保存失败不会提前推进内存，结果提交成功后的清理失败不会误报未提交。

明确的产品数值断言增加机械冲突检查，支持空格、小数与单位换算；否定、范围、条件和例外仍由 Agent 对照完整原文审阅。结构校验和引用长度无法证明语义理解正确，最终仍待人工复核。

1.9.0 补齐本机视频准备与品牌依据覆盖：Agent 自动检查并准备私有媒体组件，完整解码、逐画面 OCR、分音轨分声道转写，并读取全部画面和连续原声音频。品牌资料原句、有效规则、全部文字和素材均需逐项提交证据；缺项、跨品牌、旧版本依据和伪造读取凭据不能算完整。素材准备 complete 与审核覆盖 complete 由后台分别记录，最终仍待人工复核。

Word/Excel 内嵌图、PDF每页和品牌资料原件进入必审清单；图片、PDF和视频输出意见报告，不改原件。交接包 v2 携带品牌原件和校验信息，同名不同版本分开保留。跨设备须重新验证原件，不是实时共享数据库。

浏览器测试依赖项目验证区中的合成素材与私有测试环境；禁止对真实工作台写入测试资料。安装边界、已完成验证和未实测平台以本轮验收记录为准。

本轮增强仅接入后台数据处理及 MCP 审核合同；前端保留原有布局和简短状态，不展示覆盖统计、依据哈希、读取凭据或逐项审计面板。用户报告仅保留具体修改意见。
